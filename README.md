# 📝 Todo List Application (PHP & MySQL)

A simple **Todo List web application** built using **PHP 8** and **MySQL**, providing full **CRUD functionality** to manage daily tasks easily.

---

## 🚀 Features

- ✅ **Create** – Add new tasks  
- 📋 **Read** – View all tasks  
- ✏️ **Update** – Edit existing tasks & mark them as completed  
- 🗑️ **Delete** – Remove tasks  

---

## 🛠️ Technologies Used

- **PHP 8**
- **MySQL**
- **phpMyAdmin**
- **HTML (Forms)**
